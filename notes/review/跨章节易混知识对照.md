# 跨章节易混知识对照

> **用途**：把全书**分散在不同章节、但容易混淆**的概念集中放在一起对比。
> 考前扫一遍，能解决大部分"明明背过、一考就错"的问题。
>
> **使用建议**：这份文件**不替代各章复习**，而是在各章都复习过一遍之后做"串联检查"。
> 每张对比表都标了"在哪几章出现"，方便你回头查。

---

## 一、三个"计算机"概念（第 1 章）

| | 微处理器（MPU） | 微型计算机 | 微控制器（MCU） |
|---|---|---|---|
| 包含什么 | **只有 CPU** | MPU + 存储器 + I/O + 总线 | **CPU + 存储器 + 总线 + 外设**，全在**一片芯片**上 |
| 能单独工作吗 | **不能** | 能 | **能**（一片芯片就是一个系统） |
| 典型例子 | Intel 酷睿 | 一台电脑主机 | **STM32F103**、51 单片机 |
| 类比 | 只有"大脑" | "大脑 + 记忆 + 手脚 + 神经" | 全打包进一颗芯片 |

**包含关系**：

```
微处理器  ⊂  微型计算机  ⊂  微型计算机系统（+软件+外设）
微控制器 = 另一条思路：把微型计算机塞进一片芯片
```

> **最常考的一句话**：**微控制器不仅包含微处理器，还包含其他更多的内容。**

---

## 二、冯·诺依曼结构 vs 哈佛结构（第 1 章 → 第 2 章）

| 对比项 | **冯·诺依曼** | **哈佛** |
|---|---|---|
| 程序和数据 | **同一个存储器** | **各自独立的两个存储器** |
| 能否同时取指令和数据 | **不能**（共用一条总线） | **可以**（各有各的通路） |
| 指令/数据宽度 | **相同** | **可以不同** |
| PC 指向 | 那唯一的存储器 | **只指向程序存储器** |
| 自修改程序 | 相对容易 | **很难**（IAP 受限） |
| 代表 | Intel 8086、ARM7、MIPS | MC68、Z8、**ARM9/ARM10** |

**判断口诀**：问一句"**指令和数据是不是住在两个不同的存储器里？**"

**在后续章节的体现（第 2 章）**：

> Cortex-M3 基于**哈佛结构**，所以它**有独立的 I-Code（取指）和 D-Code（取数）总线**。
> 好处：**"入栈"和"取向量"可以同时进行**——这是中断延迟短的重要原因之一。

## 三、流水线：第 1 章的"4 段" vs 第 2 章的"3 级"

| | **第 1 章**（教材通用讲法） | **第 2 章**（Cortex-M3 实际） |
|---|---|---|
| 段数 | **4 段** | **3 级** |
| 各段 | 取指、译码、执行、**存结果** | 取指、译码、执行 |
| 公式 | **m + (n − 1)** 拍 | **3 + (n − 1)** 拍 |

> **别把这两个数字搞混**。第 1 章是"通用原理示意"，第 2 章是"这块芯片的实际结构"。

**共同的核心结论**（两章都强调）：

> **流水线没有让单条指令变快，但让整体吞吐量大幅提高。**

## 四、CISC vs RISC（第 1 章）

| 对比项 | **CISC** | **RISC** |
|---|---|---|
| 指令数量 | 多（几百条） | 少（几十条） |
| 指令长度 | **不固定** | **固定** |
| 访存方式 | 很多指令都能访存 | **只有 Load/Store 指令访存** |
| 时钟频率 | 较低 | **较高** |
| 流水线 | 难做 | **适合流水线** |
| 代表 | x86 | **ARM**、MIPS、RISC-V |

**为什么这个对比重要**：**ARM 是 RISC**，所以后面会看到——

- 指令长度固定（ARM 32 位 / Thumb 16 位）；
- **只有 `LDR`/`STR` 能访问存储器**（第 4 章反复出现这两个指令）；
- **流水线**是它的重要特征。

## 五、内核 vs 芯片（第 2 章 → 第 3 章）

| | **内核（Cortex-M3）** | **芯片（STM32F103VET6）** |
|---|---|---|
| 谁设计 | **ARM 公司** | **ST 公司** |
| 包含什么 | 取指/译码/寄存器组/运算器 + NVIC + SysTick + 总线矩阵 | 内核 + Flash + SRAM + 一大堆外设 + 时钟 + 引脚 |
| 哪一章讲 | **第 2 章** | **第 3 章** |

> **为什么不同厂家的芯片都叫"Cortex-M3"但外设完全不同**：内核是同一个，外面的配置各家不同。

## 六、三条总线：第 1 章的三总线 vs 第 2 章的四总线 vs 第 3 章的三组总线

这三个概念**层次不同**，最容易混。

| 出处 | 讲的是 | 内容 |
|---|---|---|
| **第 1 章** | **系统总线**（板级） | **地址总线 AB**（单向）、**数据总线 DB**（双向）、**控制总线 CB**（双向） |
| **第 2 章** | **内核对外接口**（片内） | **I-Code**（取指令）、**D-Code**（代码空间取数据）、**系统总线**（内存外设）、**PPB**（私有外设） |
| **第 3 章** | **片上总线层次**（片内） | **AHB**（72MHz，高性能）、**APB2**（72MHz，高速外设）、**APB1**（36MHz，低速外设） |

> **怎么区分**：
> - 第 1 章的"三总线"是**计算机组成原理层面**的通用概念（CPU 和外部世界之间）；
> - 第 2 章的"四条总线"是**Cortex-M3 内核自己往外伸的接口**；
> - 第 3 章的"三组总线"是**STM32 芯片内部设备的分级挂载方式**。

**记忆方法**：

```
第1章：AB / DB / CB        ← 通用三总线（地址、数据、控制）
第2章：I-Code / D-Code / 系统总线 / PPB   ← 内核的四个出口
第3章：AHB / APB2 / APB1   ← 芯片内部的三级总线（数字越大越慢）
```

## 七、MSP vs PSP（第 2 章）

| | **MSP**（主堆栈） | **PSP**（进程堆栈） |
|---|---|---|
| 全称 | Main Stack Pointer | Process Stack Pointer |
| 谁用 | **中断处理、异常处理、默认的普通程序** | **普通程序里，特意切换给用户任务用的** |
| 复位后默认 | **是** | 否 |
| 处理模式下 | **只能使用 MSP** | 不能用 |
| 线程模式下 | 可用 | 可用（由 CONTROL[1] 选择） |
| 目的 | 系统/中断专用 | 用户任务专用，**出错不毁系统** |

**选择规则**：**中断一律用 MSP；用户任务想隔离就用 PSP。**

**相关**：`CONTROL[1] = 0` → MSP；`CONTROL[1] = 1` → PSP。

---

## 八、MRS vs MSR（第 2 章）

| | **MRS** | **MSR** |
|---|---|---|
| 全称 | **M**ove from special register to **R**egister | **M**ove from **R**egister to **S**pecial register |
| 方向 | **特殊 → 通用** | **通用 → 特殊** |
| 用途 | **读** | **写** |

**口诀**：**MRS 里最后是 R（Register），所以结果是"进寄存器"** → **MRS = 读**。

```asm
MRS  R0, BASEPRI      ; 读
MSR  BASEPRI, R0      ; 写
```

**注意语法顺序也相反**：MRS 是 `MRS <通用>, <特殊>`；MSR 是 `MSR <特殊>, <通用>`。

## 九、PRIMASK / FAULTMASK / BASEPRI（第 2 章）

| 寄存器 | 屏蔽范围 | 快速指令 |
|---|---|---|
| **PRIMASK** | **所有中断被屏蔽**（只有最低位有效） | `CPSID I` / `CPSIE I` |
| **FAULTMASK** | **关闭异常**（比 PRIMASK 更彻底） | `CPSID F` / `CPSIE F` |
| **BASEPRI** | **屏蔽等于和低于阈值的中断**；**写 0 取消屏蔽** | 用 MRS/MSR |

> **共同点**：**只有特权级才能访问这三个寄存器。**

## 十、抢占优先级 vs 副优先级（第 2 章 → 第 7 章）

| | **抢占优先级** | **副优先级** |
|---|---|---|
| 又叫 | 组优先级 | 子优先级 / 次优先级 |
| 作用 | **决定能否打断** | **决定排队顺序**（处理"内务"） |
| 不同时 | 高抢占可以**打断**低抢占 → 形成**中断嵌套** | — |
| 相同时 | **不能打断**，只能**排队** | 按副优先级顺序处理 |

**类比**：医院急诊分诊——

- **抢占优先级** = 病情紧急程度（重症可以**立刻插队**）；
- **副优先级** = 同一紧急程度内部的排序（**不能插到重症前面**）。

**分组**：通过 **AIRCR 的 PRIGROUP 位域**把优先级位分成两段。**写 AIRCR 必须带 VECTKEY = `0x05FA`**，否则无效。

## 十一、咬尾 vs 迟来（第 2 章）

| | **咬尾**（tail-chaining） | **迟来**（late arrival） |
|---|---|---|
| 作用时机 | 中断**结束出栈**时 | 中断**开始入栈**时 |
| 触发条件 | 结束 ISR 时还有**挂起中断**，且优先级高于正在返回的 | 入栈阶段**还没执行 ISR 第一条指令**时，来了**更高优先级**请求 |
| 省掉什么 | 省掉"**一次 POP + 一次 PUSH**" | 省掉"**一次入栈**" |
| 目的 | 加速**连续中断** | 加速**抢占** |

**一句话记忆**：**咬尾管"结束"，迟来管"开始"。**

**为什么能省**：

- 咬尾：**ISR#1 结束的出栈内容 = ISR#2 的压栈内容**，所以直接跳过；
- 迟来：栈里存的还是**主程序的现场**（ISR#1 还没跑），所以直接当作"为 #2 准备的"。

## 十二、中断 vs 调用子程序（第 2 章）

| **中断** | **调用子程序** |
|---|---|
| 产生时刻是**随机的** | 程序中**事先安排好的** |
| **既保护断点（自动），又保护现场（程序）** | 可只保护断点（自动） |
| 处理程序的入口地址是**硬件确定的，用户不能改变** | 子程序的入口地址是**程序编排的** |

**共同点**：都是"跳出去再回来"，都要保存返回地址。

## 十三、挂起 vs 活跃（第 2 章 → 第 7 章）

| 状态 | 含义 | 什么时候变 |
|---|---|---|
| **挂起（Pending）** | 中断**已经被提出，但还没被响应** | 外设发出请求时置位 |
| **活跃（Active）** | 中断**正在被处理** | **执行 ISR 第一条指令后**置位，**ISR 返回时硬件清零** |
| **撤销（清除挂起）** | 请求被取消 | 向 **ICPR** 写 1 |

> **一句话**：**挂起 = 排队等处理；活跃 = 正在处理。**
> 一个中断可以**同时**挂起且活跃（处理中又来了新请求）。

**相关寄存器（写 0 都无效！）**：

| 操作 | 寄存器 | 地址起点 |
|---|---|---|
| 使能 | **ISER0～7** | `0xE000E100` |
| 除能 | **ICER0～7** | `0xE000E180` |
| 挂起 | **ISPR0～7** | `0xE000E200` |
| 解挂 | **ICPR0～7** | `0xE000E280` |
| 活跃 | **IABR0～7** | `0xE000E300` |

## 十四、EXC_RETURN 的三个值（第 2 章）

| 数值 | 返回哪里 | 用哪个堆栈 | 低 4 位 |
|---|---|---|---|
| **`0xFFFFFFF1`** | **处理模式** | MSP | `0001` |
| **`0xFFFFFFF9`** | **线程模式** | **MSP** | `1001` |
| **`0xFFFFFFFD`** | **线程模式** | **PSP** | `1101` |

**位段**：

```
bit[31:4] = 全为 1（标识）
bit3 = 0 → 处理模式；1 → 线程模式
bit2 = 0 → MSP；1 → PSP
bit1 = 0（保留）
bit0 = 1（Thumb，必须为 1）
```

## 十五、Flash vs SRAM（第 3 章）

| | **Flash（闪存）** | **SRAM** |
|---|---|---|
| 易失性 | **非易失性**（断电不丢） | **易失性**（断电就丢） |
| 速度 | 读取快，**擦除慢** | **高速** |
| 成本 | 低 | **成本高** |
| 角色 | **程序存储** | **系统内存** |
| 地址（F103VET6） | `0x0800 0000` 起，**512KB** | `0x2000 0000` 起，**64KB** |

**PPT 的原话**：

> - **内部 SRAM**：静态随机存取存储器，**高速、易失性、成本高**，**系统内存角色**；
> - **内部闪存存储器**：**非易失性、读取快擦除慢**，**程序存储角色**。

## 十六、五个时钟源（第 3 章）

| 源 | 全称 | 频率 | 内部/外部 | 主要用途 |
|---|---|---|---|---|
| **HSI** | High Speed Internal | 8MHz | **内部 RC** | 复位后默认系统时钟 |
| **HSE** | High Speed External | 4～16MHz（板上 8MHz） | **外部晶体** | 经 PLL 倍频作系统时钟 |
| **LSI** | Low Speed Internal | ≈40kHz | **内部 RC** | **独立看门狗** |
| **LSE** | Low Speed External | 32.768kHz | **外部晶体** | **RTC** |
| **PLL** | Phase Locked Loop | 可配置 | 内部 | 倍频（来自 HSI 或 HSE） |

**记忆方法**：**第 1 个字母 H/L 表示速度，第 2 个字母 S = Speed，第 3 个字母 I/E 表示内部/外部。**

**谁驱动系统时钟**：**HSI、HSE 或 PLL**（三者之一）；**LSI、LSE 作为二级时钟源**。

## 十七、AHB / APB2 / APB1（第 3 章）

| 总线 | 频率 | 挂什么设备 |
|---|---|---|
| **AHB** | **72MHz** | 高性能：内核、DMA、SRAM、Flash、FSMC |
| **APB2** | **72MHz** | **高速外设**：GPIO、ADC、USART1、SPI1、TIM1/TIM8 |
| **APB1** | **36MHz** | **低速外设**：TIM2～7、USART2/3、SPI2、I2C、DAC、PWR |

**记忆方法**：**数字越大越慢**（APB2 比 APB1 快）。

**定时器时钟 ×2 规则（必记）**：

> **APB 预分频系数 = 1 → 定时器时钟 = APB 频率；**
> **≠ 1 → 定时器时钟 = APB 频率 × 2。**

## 十八、三种启动模式（第 3 章）

| BOOT1 | BOOT0 | 启动区域 | 场合 |
|---|---|---|---|
| **X** | **0** | **主闪存存储器** | **正常运行**（最常用） |
| 0 | 1 | 系统存储器 | 串口下载程序 |
| 1 | 1 | 内置 SRAM | 调试 |

**易错**：**BOOT0 = 0 时 BOOT1 是"X"（无所谓）**。

## 十九、三种语言层次（第 1 章 → 第 4 章）

| 层次 | 例子 | 谁看得懂 | 翻译工具 |
|---|---|---|---|
| **机器语言** | `00001111 00100100 ...` | **CPU** | — |


## 二十、三个"位/字节"的大小写陷阱（第 1 章 → 第 3 章）

| 符号 | 含义 | 换算 |
|---|---|---|
| **B**（大写） | Byte，**字节** | 1B = 8 位 |
| **b**（小写） | bit，**位** | — |

**经典例子**：

```
100Mbps = 100 兆【位】/秒 = 12.5 兆【字节】/秒 = 12.5 MB/s

教材第 2 章说"1MB 位带区可存放 8Mb 变量"：
  1MB（字节）= 8 388 608 位 = 8Mb（位）
  意思是"这 1MB 里有 8M 个可以单独操作的位"
```

**记忆方法**：**大写 B 是"大"单位（字节），小写 b 是"小"单位（位）**，1 个大单位 = 8 个小单位。

## 二十一、几个"地址"的层次（第 1 章 → 第 3 章 → 第 6 章）

| 概念 | 含义 | 例子 |
|---|---|---|
| **地址** | 存储单元的编号 | `0x40010800` |
| **地址空间** | 所有地址的集合 | 32 位 → **4GB** |
| **区/块** | 地址空间的大分区 | 块 2 = 片上外设 `0x4000 0000` |
| **基地址** | 某个外设的起始地址 | GPIOA = `0x4001 0800` |
| **偏移** | 寄存器相对基地址的位置 | CRL 偏移 `0x00`、ODR 偏移 `0x0C` |
| **寄存器地址** | **基地址 + 偏移** | `0x4001 0800 + 0x0C = 0x4001 080C` |

**这条链在第 6～12 章会一直用**：

```
地址空间（4GB）
  → 某个外设的基地址
  → 加上寄存器偏移
  → 得到最终寄存器地址
  → 用指针访问它
```

**公式**：**n 条地址线 → 容量 = 2ⁿ 字节**

| 地址线 | 容量 | 地址范围 |
|---|---|---|
| 16 条 | **64KB** | `0000H`～`FFFFH` |
| 20 条 | **1MB** | `00000H`～`FFFFFH` |
| **32 条** | **4GB** | 8 位十六进制 |

## 二十二、四个"优先级数值"的陷阱

| 场景 | 规则 | 出处 |
|---|---|---|
| **一般优先级** | **数值越小，优先级越高** | 第 2 章 |
| **复位/NMI/硬Fault** | 优先级是**负数**（−3/−2/−1），**固定不可改** | 第 2 章 |
| **相同优先级** | 看**硬件优先级**：**位置编号越高，优先级越低** | 第 2 章 |
| **BASEPRI 阈值** | 屏蔽**优先级号 ≥ 阈值**的中断（**阈值越小，屏蔽越少**） | 第 2 章 |

**经典验证**：

```
PendSV（编号 14）和 SysTick（编号 15）优先级都为 0
→ PendSV 更高（编号更小）

8 级优先级的值：0x00、0x20、0x40、0x60、0x80、0xA0、0xC0、0xE0
（不是 0、1、2、3、4、5、6、7！因为高 3 位有效）
```

## 二十三、按"是否需要软件干预"分类

这张表帮你记住**哪些事是硬件自动做的**（考试常考"是否需要写代码"）：

| 事件 | 硬件自动 | 需要软件 |
|---|---|---|
| **中断压栈 8 个寄存器** | ✅ | — |
| **中断出栈恢复现场** | ✅ | — |
| **查向量表取 ISR 入口** | ✅ | — |
| **设置 LR = EXC_RETURN** | ✅ | — |
| **进出异常时切换 MSP/PSP** | ✅ | — |
| **清除外设中断标志位** | — | ✅ **必须自己写** |
| **保护 R4～R11** | — | ✅ **ISR 里用到才自己 PUSH/POP** |
| **开外设时钟** | — | ✅ **写 RCC 寄存器** |
| **配置外设寄存器** | — | ✅ |
| **设置优先级分组（AIRCR）** | — | ✅ **且必须带 VECTKEY** |
| **写向量表偏移量（VTOR）** | — | ✅（重定位时才需要） |

> **这张表最常考的一条**：**"中断压栈是硬件自动的，不需要写 PUSH 指令"**——
> 这是 Cortex-M3 相对于传统 8 位机的重大改进。

## 二十五、最容易搞混的"五组缩写"

| 缩写组 | 区别 |
|---|---|
| **B / b** | **B = 字节**，**b = 位**（1B = 8b） |
| **MRS / MSR** | **MRS = 读**（特殊→通用），**MSR = 写**（通用→特殊） |
| **ISER / ICER** | **ISER = 使能**，**ICER = 除能**（都写 1 有效，写 0 无效） |
| **ISPR / ICPR** | **ISPR = 挂起**，**ICPR = 解挂（清除挂起）** |
| **MSP / PSP** | **MSP = 主堆栈**（中断/系统用），**PSP = 进程堆栈**（用户任务用） |
| **HSI / HSE / LSI / LSE** | **H/L = 高速/低速**，**I/E = 内部/外部** |
| **APB1 / APB2** | **APB1 = 36MHz**（低速），**APB2 = 72MHz**（高速） |
| **AHB** | **72MHz**，连高性能设备（内核/DMA/SRAM/Flash） |

## 二十六、考前最后一遍：只看这些"一句话结论"

1. **微控制器 = 微处理器 + 存储器 + 总线 + 外设**，一片芯片自成系统。
2. **冯·诺依曼 = 一块存储器装两样东西**；**哈佛 = 两块独立存储器**。
3. **流水线不加快单条指令，只提高吞吐量**。
4. **ARM 是 RISC**：指令长度固定，**只有 Load/Store 能访存**。
5. **Cortex-M3 基于哈佛结构**，所以"入栈"和"取向量"能同时进行。
6. **PC 总是指向正在取指的指令**；读 PC = 当前地址 + 4。
7. **PC 的 bit0 始终为 0**，指令与字/半字边界对齐。
8. **PUSH 先减后存；POP 先读后加**。
9. **中断自动压栈 8 个寄存器**（xPSR、PC、LR、R12、R3～R0）= 32 字节，**硬件完成**。
10. **R4～R11 要 ISR 自己 PUSH/POP**。
11. **优先级数值越小越高**；复位/NMI/硬Fault 是 **−3/−2/−1**，固定不可改。
12. **抢占优先级决定能否打断，副优先级决定排队顺序**。
13. **写 ISER/ICER/ISPR/ICPR 时写 0 无效**。
14. **写 AIRCR 必须带 `0x05FA`**。
15. **咬尾管"结束"，迟来管"开始"**。
16. **EXC_RETURN：F1 = 处理模式，F9 = 线程+MSP，FD = 线程+PSP**。
17. **位带：1 位 → 1 个字**，别名地址 = `0x22000000 + (A−0x20000000)×32 + n×4`。
18. **STM32 地址空间 8 个 512MB 块**；**片上外设在 `0x4000 0000`**。
19. **使用外设前必须先开时钟**——这是第 6～12 章每章的第一步。
20. **APB 预分频 ≠ 1 时，定时器时钟 = APB 频率 × 2**。
21. **小端 = 低字节放低地址**。
22. **BOOT0 = 0 从 Flash 启动**（最常用）。
23. **GPIO 三步：开时钟 → 配 CRL/CRH → 读 IDR / 写 ODR·BSRR·BRR**。
24. **EXTI 五步：开时钟（含 AFIO）→ 映射引脚 → 选边沿 → 开 IMR → 清 PR**。
25. **EXTI 的 PR 是"写 1 清除"；定时器的 UIF 是"写 0 清除"**。
26. **80 个 GPIO 只对应 16 条 EXTI 线，同一线号同一时刻只能选一个引脚**。
27. **中断改变 CPU 执行流；事件只输出一个触发脉冲**。
28. **定时器三兄弟：PSC 管"多久加 1"，ARR 管"数到几回 0"，CNT 就是"数到几"**。
29. **定时公式两个 +1 不能漏**：`T = (ARR+1)(PSC+1)/TIMxCLK`。
30. **中央对齐用 `2×ARR`，边沿对齐用 `ARR+1`**。
31. **TIM2~TIM7 在 APB1，TIM1/TIM8 在 APB2**。
32. **定时器 ISR 三段式：判断标志 → 清标志 → 做事**。

## 二十七、中断：第 2 章"原理" vs 第 7 章"落地"

| | **第 2 章（Cortex-M3）** | **第 7 章（STM32）** |
|---|---|---|
| 讲什么 | 异常模型、NVIC 架构、压栈、向量表、咬尾/迟来、EXC_RETURN | **引脚怎么变成中断**、EXTI 结构、EXTI 寄存器、配置步骤 |
| 优先级 | 架构支持 **8 位 / 8 种分组**（PRIGROUP 0~7） | STM32 实际只用 **4 位 / 5 种分组**（0~4） |
| 典型问题 | "中断响应时硬件做了什么" | "怎么配一个按键中断" |
| 关键寄存器 | `NVIC->ISER/ICER/ISPR/ICPR/IABR/IP`、`SCB->AIRCR`、`VTOR` | 加上 **EXTI->IMR/EMR/RTSR/FTSR/SWIER/PR**、`AFIO->EXTICR` |

> **两章不矛盾**：第 2 章是"规范说最多能怎样"，第 7 章是"这块芯片实际怎么做"。
> **8 种分组 → 5 种分组**的原因是：STM32F103 只做了 4 位优先级（`bits[7:4]`），
> 而 Cortex-M3 架构最多支持 8 位。

## 二十八、外设标志位的清除方式（跨章最易错）

| 外设 | 标志位 | 清除方式 | 库函数 |
|---|---|---|---|
| **EXTI**（第 7 章） | `PR` 挂起位 | **写 1 清除** | `EXTI_ClearITPendingBit()` |
| **定时器**（第 8 章） | `UIF` / `CCxIF` | **写 0 清除** | `TIM_ClearITPendingBit()` |
| **GPIO**（第 6 章） | `BRR` / `BSRR` | **写 1 有效**（清位/置位，不是"标志"） | `GPIO_ResetBits()` / `GPIO_SetBits()` |
| **NVIC**（第 2/7 章） | `ICER` / `ISER` | **写 1 除能/使能**，写 0 无影响 | `NVIC_Init()` |

**为什么设计不一样**：

- **写 1 清除（EXTI）**：其他位写 0 天然无影响，**最安全，不需要读—改—写**；
- **写 0 清除（定时器）**：其他位必须写 1 才能保住，**手写容易误清**，所以**一定要用库函数**。

**典型错误**：

```c
EXTI->PR &= ~(1 << 0);     /* ✗ 错：PR 是写 1 清除 */
EXTI->PR =  (1 << 0);      /* ✓ 对 */

TIM2->SR = 0;              /* ✗ 错：会把所有标志都清掉 */
TIM_ClearITPendingBit(TIM2, TIM_IT_Update);   /* ✓ 对 */
```

## 二十九、四类"优先级"别搞混

| 名称 | 出处 | 规则 |
|---|---|---|
| **中断抢占优先级** | 第 2/7 章 | **数值越小越高**；决定**能否嵌套** |
| **中断副优先级** | 第 2/7 章 | 抢占相同时**数值越小越先**；**不能嵌套** |
| **复位/NMI/硬Fault** | 第 2 章 | **−3 / −2 / −1**，**固定不可改**，高于一切 |
| **BASEPRI 阈值** | 第 2 章 | **屏蔽优先级号 ≥ 阈值**的中断；**阈值越小屏蔽越少** |

> **共同点**：除了"硬件优先级按向量表编号"这一条，**其余都是数值越小优先级越高**。

## 三十、三个"通道/线路"概念（第 7、8 章）

| 概念 | 出处 | 一条通道 = 什么 |
|---|---|---|
| **EXTI 线** | 第 7 章 | 一条**边沿检测通路**（20 条线，线 0~19） |
| **定时器通道** | 第 8 章 | 一条**输入通路 + 一个 CCR + 一条输出通路**（4 个通道） |
| **DMA 通道** | 第 11 章（未做） | 一条**独立的数据搬运通路** |

> **别混**：EXTI 的"线"是**中断源**，定时器的"通道"是**捕获/比较单元**，DMA 的"通道"是**搬运引擎**。
> 三者名字都叫"通道/线"，但完全不是一回事。

## 三十一、外设使用"四步曲"在四章里的具体形态

第 1 章讲的"开时钟 → 配寄存器 → 使能 → 使用"，到具体章节长这样：

| 步骤 | **第 6 章 GPIO** | **第 7 章 EXTI** | **第 8 章 定时器** |
|---|---|---|---|
| **① 开时钟** | `RCC_APB2ENR` 的 `IOPxEN` | `RCC_APB2ENR` 的 `IOPxEN` **+ `AFIOEN`** | `RCC_APB1ENR` 的 `TIMxEN` |
| **② 配寄存器** | `GPIOx_CRL/CRH`（模式） | `AFIO->EXTICR` + `EXTI->FTSR/RTSR` + `EXTI->IMR` | `TIMx_PSC` + `TIMx_ARR` + `TIMx_CR1` |
| **③ 使能** | 配模式时就隐含使能了 | `NVIC->ISER`（使能 IRQ 通道） | `TIM_ITConfig`（DIER）+ `TIM_Cmd`（CEN） |
| **④ 使用** | 读 `IDR` / 写 `ODR`·`BSRR`·`BRR` | 在 ISR 里做事 + 清 `PR` | 在 ISR 里做事 + 清 `UIF` |

> **这张表说明**：**每章看起来不一样，但骨架完全一样**。
> 学完这三章，"开时钟 → 配置 → 使能 → 使用"就变成了肌肉记忆。

## 三十二、定时器的三个"+1"与两个"×2"

| 项目 | 公式 | 为什么 |
|---|---|---|
| **ARR + 1** | `T = (ARR+1)(PSC+1)/TIMxCLK` | CNT 从 0 数到 ARR，共 **ARR+1** 个数 |
| **PSC + 1** | 同上 | PSC 从 0 开始计数，实际分频 = **PSC+1** |
| **中央对齐 ×2** | 一圈 = `2×ARR` 个计数 | 0→ARR−1→0，上下各半 |
| **APB 定时器 ×2 规则** | `APB 预分频≠1 时，TIMxCLK = PCLK×2` | 保证定时器时钟尽量接近 72MHz |

> **这四个"数字陷阱"是第 8 章计算题的全部难点**，记住就够用了。
> （PWM 的占空比公式不在本课程范围——PPT 只提名称，不教。）
